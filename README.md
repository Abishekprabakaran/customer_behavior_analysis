# 📊 Customer Shopping Behavior Analysis & Dashboard

An end-to-end data analytics project that takes raw retail customer data through cleaning, transformation, SQL-based business analysis, and an interactive Power BI dashboard.

## 🔧 Tech Stack

- **Python** (Pandas) — data cleaning & feature engineering
- **PostgreSQL** (SQLAlchemy) — data storage
- **SQL** — business analysis queries
- **Power BI** — interactive dashboard

## 📁 Project Structure

```
├── customer_shopping_behavior.csv              # Raw dataset (~3,900 customer transactions)
├── Customer_Shopping_Behavior_Analysis.ipynb    # Data cleaning & feature engineering
├── Customer_Shopping_Behavior.sql               # Business analysis SQL queries
└── customer_behavior_dashboard.pbix             # Power BI dashboard
```

## 📓 Data Cleaning & Feature Engineering

The Jupyter notebook (`Customer_Shopping_Behavior_Analysis.ipynb`) covers:

- Handling missing values (median imputation of review ratings, grouped by category)
- Standardizing column names
- Engineering new features:
  - `age_group` — quartile-based age segmentation (Young Adult, Adult, Middle-aged, Senior)
  - `purchase_frequency_days` — converted categorical purchase frequency (e.g., "Weekly", "Fortnightly") into numeric days
- Removing redundant columns (`promo_code_used`, found to duplicate `discount_applied`)
- Loading the cleaned dataset into PostgreSQL via SQLAlchemy

## 🗄️ SQL Analysis

`Customer_Shopping_Behavior.sql` contains 10 business-driven queries, including:

| # | Question |
|---|----------|
| 1 | Total revenue generated by male vs. female customers |
| 2 | Customers who used a discount but still spent above average |
| 3 | Top 5 products by average review rating |
| 4 | Average purchase amount: Standard vs. Express shipping |
| 5 | Spending comparison: subscribers vs. non-subscribers |
| 6 | Top 5 products by discount usage rate |
| 7 | Customer segmentation — New, Returning, Loyal (by purchase history) |
| 8 | Top 3 best-selling products within each category |
| 9 | Subscription likelihood among repeat buyers (5+ previous purchases) |
| 10 | Revenue contribution by age group |

## 📈 Power BI Dashboard

`customer_behavior_dashboard.pbix` visualizes the above insights, including:

- Revenue breakdown by demographic segments
- Discount and promo effectiveness
- Customer loyalty segmentation
- Product and category performance
- Subscription behavior vs. spending patterns

## 📌 Key Insights Explored

- Revenue contribution across demographic segments
- Impact of discounts and promo codes on purchase behavior
- Customer loyalty tiers based on purchase history
- Best-performing products and categories
- Correlation between subscription status and spending
